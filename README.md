# 赵逸飞 · 个人简历

一个轻量、响应式的个人简历与视觉内容作品页，使用原生 HTML、CSS 和 JavaScript 实现，无需安装依赖。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 页面内容

- 个人简介：IP操盘手、无限进步、北京、火锅与旅游
- 视觉内容：根据提供的插画素材整理的三张作品卡片
- 联系方式：微信号复制按钮与电话链接
- 交互：鼠标聚光、作品卡片倾斜、磁吸按钮、滚动显现和悬停动画
- 响应式布局，并尊重系统的减少动态效果设置

## 文件

- `index.html`：页面结构、样式与交互逻辑
- `assets/zhaoyifei-portrait.png`：个人半身照
- `assets/works/`：作品展示图片

编辑 `index.html` 和 `assets/` 中的图片即可更新页面。
