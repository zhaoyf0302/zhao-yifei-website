# 赵逸飞 · 个人简历

一个轻量、响应式的个人简历与视觉内容作品页，使用原生 HTML、CSS 和 JavaScript 实现，无需安装依赖。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 页面内容

- 个人简介：IP操盘手、无限进步、北京、火锅与旅游
- 视觉内容：13 张图片按“湖畔奇遇 / 盔甲骑士的日常 / 盔甲宇宙”拆成独立板块
- 联系方式：微信号复制按钮与电话链接
- 交互：头像已统一为蓝橙漫画插画风；照片卡片有远中近三层视差、人物独立浮动、4 秒角色动作循环、指针倾斜和点击放大；另有自定义光标、磁吸按钮与滚动进度
- 响应式布局，并尊重系统的减少动态效果设置

## 文件

- `index.html`：页面结构、样式与交互逻辑
- `assets/zhaoyifei-portrait.jpg`：统一插画风格的个人半身肖像
- `assets/works/`：作品展示图片（压缩 JPEG）

编辑 `index.html` 和 `assets/` 中的图片即可更新页面。
